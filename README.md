# Flow in a Day – Yoga Class Booking Website

A responsive yoga class booking website developed as a university group project for the Master of Information and Communications Technology program at Western Sydney University.

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- AJAX
- jQuery
- MySQL

## Features

- User registration and login
- Yoga class booking
- User profile management
- Contact enquiry form
- Admin dashboard
- CRUD functionality for users and classes
- Responsive web design

## My Contributions

- Developed front-end and back-end functionality using PHP, JavaScript, HTML, and CSS.
- Implemented user authentication, booking, and profile management features.
- Built administrative CRUD functionality connected to a MySQL database.
- Participated in testing, debugging, and improving usability throughout the project.

## Live Demo

The original project was hosted on the Western Sydney University student server. As the university server is no longer available, the live demo is no longer accessible.

## Database

The original MySQL database was hosted on the Western Sydney University server. As access to the server has since been removed, the database dump (`.sql`) is not available in this repository. The source code is provided to demonstrate the application's architecture, implementation, and development approach.
